# 检查范围、导出与验收证据

工厂任务在单组件检查之外，还需执行 [工厂级流程](factory-workflow.md) 的尺度、坐标、数量语义、接口与运行空间核对；二者不能互相替代。具体功能区净距或真实设备精度缺少依据时，保留待确认状态。

## 检查记录

结果使用：通过、发现问题、已解释的例外、未检查、不适用。记录对象/部件、实际方法与证据。超预算跳过或工具不支持属于未检查，不能记为零缺陷。

| 层面 | 至少覆盖 |
|---|---|
| 参考一致性 | 特征表、主尺寸、正反视角、不对称性、部件数量 |
| 层级与复用 | 根节点、功能分组、静态合并、运动链、原点和拼接接口 |
| 几何 | 重复面/对象、退化面、异常点边、孔洞、相交、法线与修改器最终结果 |
| 视觉 | 灰模、线框、材质、多视角、目标观察距离、单面显示 |
| 运动 | 零位、代表性中间姿态、极限姿态、下游随动与其他分支不动 |
| 交付 | 文件存在、贴图齐全、尺寸单位、轴与层级、回读结果、按任务验证目标软件 |

数字检查与观察互补：对象统计不能证明相似性，漂亮渲染不能证明无重复面，导出成功不能证明可迁移。

## 自带只读脚本

`scripts/audit_asset.py` 只检查指定根及其子树，默认检查修改器求值网格。它提供：

- 层级树、直接子节点数量、重复或默认风格命名提示；对象位置、缩放、包围盒、材质数。
- 非有限数值、零面积面/零长度边、松散点边、边界与非流形边。
- 同一对象内近同位顶点候选、量化坐标相同的面；跨对象量化坐标相同的面。
- 单个连通封闭壳体的绕序一致性与有符号体积提示；负行列式/非单位缩放。
- 图像贴图缺失提示，并区分打包/生成图片与外部文件。

它不会自动修复，不改变选择、变换、Mesh、材质或文件。`asset_acceptance` 始终不是总体通过结论。提示中的异常封闭壳体可能是有意内腔，近同位点可能是硬边或装配接口，必须判断。

明确未覆盖：部分重叠或不同三角化的共面面片、近共面 Z-fighting、自相交、连续碰撞、UV 拉伸/重叠、贴图视觉、着色切线、机械可达性、参考图相似度。脚本的完全重合面检查是坐标量化匹配，不等价于“容差内任意两面必定检出”。

默认数值匹配容差按包络尺度估计，仅用于候选查找。可以传 `--tolerance` 指定世界坐标中的 Blender 单位；不应将其当作工程毫米公差。`--max-direct-children` 默认 24，仅是复查提示；`--max-vertices` 控制昂贵点邻域检查，`--max-faces` 控制整项资产的面签名预算，超过时报告 skipped。错误变换、非法数值或无法求值也会明确保留部分检查未完成的状态。

报告可能发现合理开放薄片、独立壳体或导入拓扑；禁止为了消除所有提示进行无差别合并/填洞。区分本次任务需要解决的问题和有证据的设计例外。

## 手动/图像检查补足

1. 用正、背、侧、顶和斜视检查主要几何；用户未提供的背面也要检查是否漏建/缺面。
2. 在任务副本或可恢复的视图设置中使用 Face Orientation 与背面剔除检查；双面渲染正常不算绕序通过。
3. 转动视角、改变观察距离看共面闪烁和条纹。对模型内部用隔离/xray检查，找面板交叠、远处碎片、无效内部面。
4. 对活动机构分支逐个测试，确保所有本应随动的固定件也随动；记录运动假设、姿态与检测方法。
5. 有碰撞要求时区分包围盒筛选、表面相交、封闭体包含、离散姿态采样和连续扫掠。采样若干姿态无碰撞不能声称整个行程无碰撞。
6. 用中性材质/光照观察硬边和曲面，再审查真实材质、贴图尺度、透明面和缺图。

## 导出

- 从交付根筛选对象，只导出该资产及其必要子节点。明确过滤切割体、参考图、检验辅助物、相机和展示灯光。
- 根基准按用途设置：落地安装、模块连接或装配基准。不把所有资产一律放包围盒中心，也不把活动枢轴强行归零。
- 源文件保留可编辑结构；必要时在导出副本转换修改器、曲线或实例。确认转换保留材质、UV、厚度和法线。
- FBX 的单位/轴转换与目标引擎导入设置一起验证；不复用未经验证的版本参数。
- GLB 的 PBR 支持不代表任意 Blender 节点都会原样迁移；仅目标支持的扩展和材质可按实际结果承诺。
- 贴图使用可迁移路径/打包方式；重新在原路径以外加载验证依赖，防止只有本机能看到材质。
- 合并对象减少节点不保证减少所有材质槽或绘制调用；优化后检查材质共享和运行时资源。

## 回读与交付

在干净 Blender 进程或独立场景回读导出文件，比较主尺寸、安装基准、对象名称/父子结构、材质槽、顶点/三角面统计及活动节点。

导出前后顶点数因硬边、UV和三角化而改变时，按几何表面与用途判定，不强制计数逐项相等。需要动画时检查实际绑定和采样，不能仅检查同名节点存在。

对于用户明确要求的目标软件，使用隔离验证工程。只完成 Blender 回读就准确写 Blender 回读通过；不声称 Unity、Unreal 或现场仿真已验收。

正常交付包括可编辑源文件、用户需要的交换格式、必要贴图、简短尺寸/层级说明与已完成的证据。参考图片、完整日志和大批预览按任务需要保留，避免无用途的交付文件堆积。

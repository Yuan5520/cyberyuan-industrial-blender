## 隔离脚本自测

`scripts/self_test.py` 在全新 Blender 后台进程中构造少量好/坏样本，验证审计能发现实际几何和层级缺陷，同时不修改被审计场景。它不调用 MCP，不打开用户项目，不替代参考图建模测试。

```sh
"$BLENDER_EXE" --background --factory-startup --python-exit-code 1 \
  --python "$SKILL_DIR/scripts/self_test.py" -- --out-dir "$ISOLATED_TEST_DIR"

"$BLENDER_EXE" --background --factory-startup --python-exit-code 1 \
  --python "$SKILL_DIR/scripts/self_test.py" -- \
  --out-dir "$ISOLATED_TEST_DIR" --verify-roundtrip
```

使用空的独立输出目录，不能指向已有项目或已有正式资产。第一次创建夹具和交换文件；第二次在新进程回读并核对。若某格式不可用，记录对应测试未运行，不能用其他格式的成功代替它。

脚本测试覆盖：合理刚性/门层级、重复面与重合对象、反向壳体、负缩放、退化面和松散点、过度平铺、合法开放薄片、修改器求值、审计只读性，以及简单 FBX 的尺寸、父子关系与枢轴随动。

## 用户与 agent 的实际测试任务

| 场景 | 输入 | 应观察到的行为 | 不合格信号 |
|---|---|---|---|
| 非对称加工机柜 | 前后两张图，护罩与两个台子不同 | 先列关键特征并建立灰模，匹配方向、数量、比例 | 只看一张图；提前花时间渲染；改成通用对称柜 |
| 可动柜门 | 门框、把手与滑轨示意 | 固定部分合并；把手随门；轴心/行程有依据 | 门框随门移动；固定螺丝全部独立；盲目应用活动枢轴 |
| 仓储与堆垛机 | 总装图、行走/升降/伸缩要求 | 功能分组和真实随动链，合理刚性合并 | 根节点下几百个子物体；货架随堆垛机移动 |
| 轨道模块 | 头/中/尾与接口尺寸 | 同一拼接基准，可重复中段，导出无场景偏移 | 每段不同截面；只能在原场景拼好 |
| 几何缺陷修复 | 重复面、反向壳、合理薄片并存 | 区分缺陷类型，局部修复后回看与回读 | 全场景按距离合并；一律填洞；开双面掩盖反向面 |
| 纯模型状态灯 | 结构/尺寸图与分色控制要求 | 固定几何简明、材质槽合理、展示灯光不入交付 | 自动给开发项目加灯光脚本；以颜色数量决定对象数量 |
| 现有工作现场 | 含无关对象和未保存修改的文件 | 检查范围，保留现场，增量修改 | 清空场景、覆盖唯一源文件、重跑生成导致重复物体 |

这些任务应在独立资产目录中逐个测试。先选一个小但有非对称结构和活动件的机柜；再测复杂总装，避免用第一个实际任务同时覆盖全部问题。

记录输入、输出、用户指出的具体偏差、原因、修改与再验证结果。优先修正能够解释失败的规则或脚本；不要增加大量与失败无关的要求。没有完成实际图像、MCP 或目标引擎测试，就明确保留该验证空白。

## 工厂级行为样例（v0.2.0）

| 场景 | 应观察到的行为 | 不合格信号 |
|---|---|---|
| CAD 文件头与标注单位不一致 | 用独立尺寸锚点和块缩放核对，建立可逆坐标合同，再统一制作 | 仅切换 Unit Scale 就宣布几何比例正确；全部按文件头机械缩放 |
| 图中只有区域和工位符号 | 区分组件类型、实例、分配区与示例；给出可读原图预览 | 用格子数冒充真实设备数量；将整个区域挤出为一台设备 |
| 多种设备仅有平面标签 | 每类独立核查资料；不足时按类型检索通用结构，标记估算 | 整厂只搜索一次；所有设备套同一箱体；未经检索就说资料找不到 |
| 已有完整且匹配的组件资料 | 核查单位/原点/结构与许可后复用，重复实例只做摆放 | 为形式重搜下载；逐实例重复造型；用户已允许通用仍逐件问批准 |
| 多代理共用一个实时 MCP | 并行资料和独立文件；共享场景写入排队，主代理掌握总装 | 各代理同时切场景、清空选择或保存同一个 Blender 文件 |
| 多代理尺度或接口版本冲突 | 检查全局合同版本，将错误类型回修，其他独立任务继续 | 总装阶段按目测缩放；强行拉伸门、孔和圆轴匹配分配区 |
| 厂房斜边、缺边与面积文字矛盾 | 保留真实轮廓，推导闭合单列来源，不用包盒替代后声称精确 | 自动规整矩形或凑面积文字；把推导边界当实测 |
| 组件本体在区内但门碰 HMI/邻机 | 分别检查本体、运动与检修空间，回组件/实例修正 | 只查 AABB 在区内；节点能动即宣称全行程无碰撞 |
| 基础网格正常、薄件倒角塌缩 | 查求值网格，按特征修正倒角并复核共享实例 | 只查基础网格；全局删小件；跳过检查后记通过 |
| 组件库和原有工程同时存在 | 独立保存交付，核对依赖和实际活动路径，另给陈列视图 | 把全部旧场景打包进工厂文件；让重叠原点资产充当审阅图 |

2026-10-29 的真实 DWG 案例已完成局部坐标装配、组件/实例分离、求值网格与导出回读，并留下各项覆盖范围。它也暴露了逐类参考检索和通用外形区分不足的问题。因此既有案例不能作为新增“每类完整检索 + 多代理隔离”流程已经端到端验收的证据。v0.2.0 本轮先执行结构/链接验证与独立情景评审；真实多代理建模、整厂性能、连续碰撞和目标引擎仍需后续实际任务验证。

# 工业硬表面几何与材质

## 按用途选择做法

| 用途 | 建模重点 |
|---|---|
| 工业实时可视化 | 合理中等复杂度、控制倒角与着色、复用材质、合理对象数 |
| 近景产品展示 | 真实圆角与厚度、曲面连续性、表面处理与细节尺度 |
| 面数受限资产 | 保留轮廓与活动接口，将适合的细节烘焙到贴图 |
| 机构交互 | 枢轴、装配关系、行程空间、运动部件边界 |

不要统一添加 Subdivision Surface，也不要给所有零件固定 2 cm 倒角。倒角依据板厚、制造特征、物体尺度和观察距离确定。钣金、铸件和橡胶边缘的处理不相同。

同一刚性 Mesh 中的薄标条、小按钮或浅槽可能使统一倒角在求值后塌缩，即使基础网格没有退化面。检查受影响特征，按厚度调整倒角范围/宽度或特征权重，再复查所有共享该几何的实例；不要通过删除全部小细节或忽略求值结果消除报告。

## 面、点与壳体

| 问题 | 判断与处理 |
|---|---|
| 重复顶点 | 同坐标只是候选；可能是合法硬边或不同壳体。按范围与数值容差检查，不能全场景焊接 |
| 完全重复面 | 同一 Mesh 与不同对象都要检查；顶点索引不同仍可能覆盖同一空间表面 |
| 部分共面/近共面重叠 | 完全重复签名查不到。结合几何重叠检测与移动视角观察；检查面板、底面、贴花和模块接口 |
| 孤立点边/小碎片 | 查未参与面构造的点边、异常小壳体和远离包络的物体；先辨认真实零件再删除 |
| 退化面/零长度边 | 找零面积、共线顶点、错误挤出等，修复后重新检查最终修改器结果 |
| 非流形与孔洞 | 封闭壳体和有意开放的薄片规则不同。识别 T 接、内面、漏面，不一律填洞 |
| 壳体反向 | 对封闭、朝外实体检查绕序；空腔内壁、开放面与嵌套壳体要结合表面语义判断 |
| 自相交/组件穿插 | 区分错误穿透、允许的装配关系和不可见结构。AABB 重叠只是筛选，不是网格碰撞结论 |
| 单面缺失 | 看 Face Orientation、绕序及镜像/负缩放结果，并以背面剔除观察；不要用双面材质掩盖错误 |

Merge by Distance 只处理距离条件下的顶点，Delete Loose 只处理松散几何，二者都不是“清除全部内部面”的工具。容差须相对资产尺度和最小真实缝隙选择，数值去重容差不是制造公差。

重影也可能受深度精度、栅格/纹理采样影响。先确认重复表面；不要看到摩尔纹就无差别删几何，或用改变相机远近面掩盖模型重复面。

## 着色与拓扑

- 面的正反绕序、着色法线和法线贴图是不同问题，分别检查。Weighted Normal 调整着色，不会补洞或删除重复面。
- 在灰模/MatCap 和有方向变化的光照下观察平面是否出现异常渐变、边缘是否夹痕、圆柱是否轮廓分段明显。
- 硬边与平滑边按形状设计，按需要使用角度平滑、倒角法线或加权法线；保留真实锐边。
- 静态平坦区域可以使用合理三角面或 n-gon。细分、弯曲、变形区域需要适合的布线；不以“全四边面”代替用途判断。
- 非平面 n-gon 的三角化可能改变结果。烘焙和交付保持一致的三角化与切线空间，并验证导出副本。
- 源文件保留可编辑过程，导出副本求值修改器。不要为了输出不可逆地破坏唯一的源文件。

## PBR 与 UV

按真实表面而非底层材料命名与赋值：喷漆钢板表面通常表现为非金属涂层，裸露钢材才按金属表面处理。粗糙度、反射、倒角和真实尺度共同决定质感，不能只调颜色。

- 使用可迁移的 Principled/PBR 输入作为起点：Base Color、Metallic、Roughness，按需 Normal、AO、Opacity/Transmission。
- 通常颜色贴图按其色彩编码读取；法线、粗糙度、金属度、AO 等数据贴图使用 Non-Color/线性数据处理。不要对所有图片统一套 sRGB。
- 色彩图避免包含方向性灯光和大块烘焙阴影；贴图细节应符合实际表面尺度。
- 需要纹理时检查 UV 拉伸、接缝、纹素密度和边界留白。平铺材质可有合理 UV 重叠；唯一烘焙图和 lightmap 有不同要求，不一律禁止重叠。
- 检查法线贴图的切线空间/绿通道约定，目标软件确认后再转换。Roughness 与 Smoothness、通道打包也需按目标适配。
- 程序材质和复杂 Blender 节点不保证进入 FBX/GLB 后等效；需要时烘焙贴图，回读或在目标环境验证。玻璃、透射与透明度尤其需要核对。
- 避免每个螺丝新建一份相同材质；合理共享材质和纹理，保留确有独立控制需求的槽位。

使用普通中性照明审查材质，再制作展示图。展示灯光和相机与资产分集合管理；交付纯模型时过滤它们，灯罩发光意图与 Light 对象区分记录。

## 性能与细节分配

按同时显示的设备数量、观察距离和目标平台考虑三角面、运行时顶点、材质槽、透明表面和贴图内存。没有用途依据不规定统一预算。

UV 接缝、硬边或材质边界可能使导出/运行时顶点数增加，这不自动等于重复顶点错误。面数没有变化也不代表材质和绘制成本没有增加。

细节优先级：轮廓与接口 → 功能结构 → 可见连接与表面特征 → 微小装饰。不可见且无交互用途的内部件可简化；用户要求拆装或内部展示时再提高深度。高密度重复件优先使用可控复用，交付时仍按组件和运动边界整理。
